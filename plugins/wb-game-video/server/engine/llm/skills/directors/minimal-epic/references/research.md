# 调研 · 极简史诗 · 以小写大（minimal-epic）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 丹尼斯·维伦纽瓦（Denis Villeneuve）的当代科幻史诗一路——极简、克制、以规模承载叙事。代表作：《银翼杀手 2049》《沙丘》《降临》《边境杀手》。

## 核心美学要点

- "规模即叙事"：把渺小的人放进巨大空间，用构图中人物的位置（边缘/居中）传达权力关系，而非靠台词。
- 极简剪辑：一场戏 3-5 个长镜（10-20s），拒绝碎切与特写堆砌。
- 静为主、缓运镜为点睛：baseline 是稳定静态构图，极缓推进 / 水平 truck 只在命运转折时让"规模缓缓展开"。
- 单一自然光源 + 大量阴影留白；沙褐青灰大地色系的极度单色化。
- 节奏如地质运动，静默即配乐；同位置匹配切（同门昼夜切换）做时间跳接。

## 落地到本 skill 的手法

- 景别以 extreme wide/wide 立基，情绪 / 转折点才切 medium/close 的"宏大↔渺小"落差。
- 短焦（24-35mm）强调纵深；沙褐青灰单色调。
- 签名极缓大运镜、同位置匹配切列为"稀缺点睛"；紧张段反招牌收短镜头、加快切点。
- 时长窗口：转折 12–15s 一镜缓推，静拍约 4s。

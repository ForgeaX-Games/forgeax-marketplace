# 调研 · 情绪浮光 · 霓虹散文（mood-neon）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 王家卫（Wong Kar-wai）的情绪流 / 散文式电影语言与 step-print 抽帧升格。代表作：《重庆森林》《花样年华》《堕落天使》《春光乍泄》《2046》。
- 关键手法参照：《重庆森林》前段狂乱手持抽帧、后段锁定放慢——同一作者在不同段落处理相反（成品里写成"同一流派不同段落"的通用陈述）。

## 核心美学要点

- 拍"感觉"而非"事件"：时间模糊，几秒凝视跨越数年错过。
- step-print（抽帧升格）：同一动作叠多种速度制造"记忆感"，只压情绪最浓的一两拍。
- voice-over 独白与画面错位；溶解 / 叠印转场为主。
- 超浅景深（50-85mm，f/1.2-1.8）背景化光斑；单侧霓虹半脸光；高饱和做脏、低对比的"洇水胶片"。
- 节奏散文诗：无固定节拍，动作可突然停顿再恢复。

## 落地到本 skill 的手法

- medium-close 为主 + 框架缝隙窥视；情绪峰值切手/钟/烟特写。
- step-print 抽帧升格 / 定格 / 叠印列为稀缺点睛；紧张段反招牌给实在动作+更快节奏。
- 单侧霓虹半脸光 + 超浅景深光斑 + 高饱和低对比为底色。

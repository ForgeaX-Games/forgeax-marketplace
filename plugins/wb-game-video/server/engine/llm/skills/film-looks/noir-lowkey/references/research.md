# 调研 · 黑色电影低照度高对比（film-noir low-key）

> 公共布光/调色技法，非某部影片。成品只用原创描述。

## 核心

- Low-key = 强硬键光、极少/无补光，高键补比(常 8:1 以上)，深黑硬影、少中间调。来源：Filmmakers Academy、StudioBinder《Low Key Lighting》、filmlocal。
- 根在文艺复兴 chiaroscuro，40s–50s 成黑色电影标志。来源：StudioBinder、darkmansdarkroom。
- 母题：硬定向阴影、剪影、百叶窗条纹光、荷兰角。来源：darkmansdarkroom、filmlocal。
- 硬光源(Fresnel/spot)造锐利阴影，softbox 不属正统 noir。来源：filmlocal。

## 落地到调色

高对比近单色 + 深硬阴影 + 亮镜面高光 + 少中间调 + 冷蓝点缀。整片恒定，昼夜都硬光低照。

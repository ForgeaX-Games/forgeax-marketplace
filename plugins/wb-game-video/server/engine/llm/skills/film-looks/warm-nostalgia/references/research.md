# 调研 · 暖阳怀旧胶片（16mm 暖调 + 晕光 + 颗粒）

> 公共胶片仿真技法，非某部影片。成品只用原创描述。

## 核心

- 暖胶片观感四件套：颗粒(grain)、晕光(halation)、色密度、高光柔滚降。来源：filmmakingelements《Film Look in DaVinci Resolve》、aaapresets。
- Halation = 亮光穿过乳剂反射回来二次曝光(偏红层)，在高对比边缘生暖红橙晕；hue≈10，偏金则 40。来源：Luttie、mononodes。
- 暖怀旧：金色中间调、微抬黑位、bloom、细颗粒(16mm 500T 预设)。来源：cutsio《Dreamy Glow》、filmmakingelements。
- 颗粒放末端、亮部略多于暗部更真。来源：aaapresets。

## 落地到调色

金琥珀中间调 + 奶化黑位 + 暖红晕光 + 细颗粒 + 柔滚降。整片恒定，昼夜靠光源色温与晕光浓度。

# 调研 · 古铜史诗（日晒琥珀暖调 · 历史史诗）

> 公共历史史诗调色气质，非某部影片。成品只用原创描述。

## 核心

- 暖琥珀/古铜主色 + 赭褐深影：属"暖侧的冷暖对比"用法，暖高光对压深的暗部，靠对比塑壮阔。参见冷暖互补原理(teal-orange 的暖侧变体)。来源：PetaPixel/Morphic（互补对比原理）。
- 尘雾大气(atmospheric haze)增厚重与纵深；高对比强化史诗尺度。参见 chiaroscuro 的明暗塑形。来源：MasterClass《Chiaroscuro》。
- 日晒/黄沙的金色 + 火把暖光作夜景光源，保持整片暖古铜不发冷。

## 落地到调色

琥珀金高光 + 赭褐深影 + 尘雾 + 高对比古铜暖。整片恒定，昼夜靠暖光源(烈日/火)与暗部深度。

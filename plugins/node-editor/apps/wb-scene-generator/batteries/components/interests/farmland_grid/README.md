# 农田生成 (farmland_grid)

在单张可用区域掩码上用三种布局算法生成农田分区，输出含田垄/田地/作物点位的单张多值网格。

> **DataTree 形式**：每次只处理单张 `inputGrid`，网格列表的 fanout/重组由引擎自动完成。

## 功能特点

1. **三种布局形式**：规则网格（grid）、水平条带（strip）、BSP 自由划分（bsp），适应不同农场风格
2. **多值输出**：单一网格涵盖田垄（1）、田地（2）与各作物点位（3-6，按 plantDensity 稀疏），可直接用于渲染或后续处理
3. **掩码约束**：只在输入掩码非零区域内生成，外部保持 0，天然支持任意形状的农场边界
4. **可复现**：BSP 算法通过随机种子保证结果可复现；grid/strip 为纯确定性算法

## 适用情况

- 星露谷物语/牧场物语风格的农场地图生成
- 需要将一块空地划分为多个可种植地块的场景
- 与室内/室外地形掩码结合，快速填充可用耕地

## 基本使用方法

1. 将可种植区域的掩码网格（非零 = 可用区域）连接到 `inputGrid` 端口
2. 在 `layout` 下拉框选择布局形式
3. 调整 `plotWidth`、`plotHeight`、`pathWidth` 控制地块大小和小径宽度
4. 执行后，`outputGrid` 中田垄值为 1，田地为 2，作物点位为 3-6，空白为 0

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| inputGrid | grid (item) | - | 单张可种植区域掩码，非零为有效格子 |
| layout | string | grid | 布局算法（见下方说明） |
| plotWidth | number | 4 | 地块列数，最小 2（grid/bsp 有效） |
| plotHeight | number | 4 | 地块行数，最小 2（所有算法有效） |
| pathWidth | number | 1 | 地块间小径格数，最小 1 |
| seed | number | 0 | 随机种子（仅 bsp），0=时间戳 |
| plantDensity | number | 0.9 | 作物点位铺设密度（0~1），1=满铺，0=全田地 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| outputGrid | grid (item) | 单张多值网格（见下方值说明） |
| outputNameList | array (item) | 名称清单，仅含实际出现的 id（作物点位 type=asset，其余 tile） |

## 布局算法说明

| 算法值 | 名称 | 特点 |
|--------|------|------|
| `grid` | 规则网格 | 按 plotWidth × plotHeight 均匀划分，相邻地块类型自动区分，排列整齐 |
| `strip` | 水平条带 | 按 plotHeight 行高切分为水平条带，每条带为一种地块类型，路径感强 |
| `bsp` | 自由划分 | 递归 BSP 切分，产生大小不一的地块，更自然有机，受 seed 控制 |

## 输出值含义

| 值 | 含义 | type |
|----|------|------|
| 0 | 空（原始掩码为 0 的区域） | - |
| 1 | 田垄（地块间隔离带） | tile |
| 2 | 田地（未铺作物点位的地块格） | tile |
| 3 | 水稻点位 | asset |
| 4 | 小麦点位 | asset |
| 5 | 玉米点位 | asset |
| 6 | 蔬菜点位 | asset |

每个地块整体被分配为一种作物类型，地块内单元格按 `plantDensity` 随机命中为作物点位（asset），未命中则为田地（tile）。可通过下游 `grid_split_by_value` 按值分离田垄/田地/各作物。

## 使用示例

### 输入示例

```json
{
  "grid": "...(20x20 楼层掩码)...",
  "layout": "grid",
  "plotWidth": 5,
  "plotHeight": 4,
  "pathWidth": 1,
  "seed": 0
}
```

### 输出效果（示意）

```
grid 模式（plotWidth=4, plotHeight=3, pathWidth=1）：

0 2 2 2 2 1 3 3 3 0
```

## 注意事项

1. **掩码约束**：输出网格尺寸与输入完全一致，输入为 0 的格子输出保持 0
2. **参数适配**：plotWidth/plotHeight 过大时，部分地块会被掩码边界截断，属正常现象
3. **bsp 最小尺寸**：BSP 的最小地块尺寸取 min(plotWidth, plotHeight)，建议设 ≥ 3 以避免过小地块
4. **小径宽度**：pathWidth=1 已足够分隔，设 2 可获得更宽的田间小路效果

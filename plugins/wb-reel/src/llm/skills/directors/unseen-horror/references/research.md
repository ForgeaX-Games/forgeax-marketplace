# 调研 · 未见之惧 · 过程恐怖（unseen-horror）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 温子仁（James Wan）的古典恐怖调度与声音设计。代表作：《电锯惊魂》《潜伏》(Insidious)《招魂》《招魂 2》(The Conjuring 2)。

## 招牌手法（要点）

- **"过程比结果吓人"**：把恐惧建立在期待上，迟迟不给答案，jump-scare 推到临界才炸。
- **声音即建筑**：寂静 → 画外杂音（地板吱、音乐盒、拖拽声）→ 标点式巨响；声音先于/替代画面引导注意力。招牌桥段：小女孩进屋顶门，镜头留在她身上，画外传来"被撞/被拖走"的声音——纯声音设计点燃想象。
- **负空间**：留大量空白让观众自己把房间"画出来"，威胁常在画外/暗处；先建立空间地图再"破坏"它。
- **缓推长镜**：走廊倒退跟拍等长镜头把恐惧摊在实时里逐步揭开空间（《招魂 2》18 秒走廊长镜）。
- **锁定跳切**：机位不动、画框静止，鬼影一眨眼移动巨大距离——让"盯着看"变徒劳（"看见/看不见都恐怖"）。
- **手持**：留给角色恐慌/失控的主观抖动。
- **古典工整 + 可读性**：混乱前先建立地理，让升级可信；even 动作段也强调 readability。
- **图腾/意象锚点**：玩偶、修女等持续性视觉母题（跨片复现）。

## 落地到本 skill 的手法

- wide/medium 建立负空间，威胁留画外/暗处，关键处才切 close。
- 缓推长镜 baseline，恐慌时才手持抖动；锁定跳切 / 画外一击 / 鬼影露脸列为稀缺点睛。
- 低照度大阴影 + 冷调低饱和旧质感 + 声音先行为底色。

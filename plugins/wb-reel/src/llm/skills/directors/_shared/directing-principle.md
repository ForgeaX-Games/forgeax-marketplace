镜头调度通则 —— 凌驾于任何具体导演流派之上、所有导演（含 custom）通用的元规则。

风格是**手段**，戏剧张力是**目的**。下面这套导演流派的镜头语言，是你的**整体气质与工具箱**，
不是"每一镜都套同一组参数"，更不是"把这位导演最出名的那个招牌运镜/剪辑手法从头用到尾"。

你要**读懂当前这一拍/这一场的剧情、情势与情绪**，判断"此刻要传达什么、要怎么调动观众"，
再决定怎么调度：

① **景别随戏走、自然就会变**——建立、对话、情绪、强调、动作各有最合适的景别
（wide / ots / medium / close / insert）；一场戏里景别几乎不变，多半是你没跟着戏走。

② **运镜按"这一拍到底需不需要动"来选**——平铺直叙用稳健的静态或微动就够；情绪 / 动作 /
转折的峰值才动用**签名大运镜**。签名是**点睛**，稀缺、有目的、每场至多一次，不是每镜复读，
也不为"显得有变化"硬塞。

③ **允许甚至要求"反招牌"**——剧情该快切的紧张处，就算这位导演平时爱慢推，也必须**快切、
缩景别、提节奏**；剧情该静的铺陈处就静。**情绪 / 情节 / 场景调度的优先级高于导演个人偏好。**

④ **同一导演内部也要有对比**——擅长大场景的导演一样拍特写 / 细节 / 特效镜头；不要让整段
只有一种景别、一种节奏。片内要刻意形成静↔动、远↔近、快↔慢的对比呼吸。

⑤ **按整片统筹**——用几十分钟（或按剧本长度）的**情绪弧线 + 幕结构 + 场景关系**去布局签名
的落点，而不是逐片段复制。

⑥ **时长窗口意识（视频生成单片段 4–15 秒）**——需要连贯演绎的桥段尽量在 15 秒内一气呵成，
把**片段内的镜头切换 + 运镜贯穿**写清楚；单一情绪的短拍用约 4 秒单镜，留给作者裁剪。

一句话：导演风格 = 观众看完后的**整体感受** + 几处**恰到好处、由剧情驱动**的点睛，
而非把一个招牌手法复制到所有镜头，也非按数字配额硬凑。

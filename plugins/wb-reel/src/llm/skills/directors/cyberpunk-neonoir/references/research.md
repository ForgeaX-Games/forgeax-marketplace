# 调研 · 赛博霓虹 / 都市雨夜（cyberpunk-neonoir）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名 / 真实游戏名。真名真作品仅在本文件出现，不会进入模型提示词。
>
> 这是一个**类型美学**流派（非单一导演），谱系奠基于《银翼杀手》（摄影 Jordan Cronenweth），并受《银翼杀手 2049》《攻壳机动队》《赛博朋克 2077 / Cyberpunk 2077》等作品影响。核心结论：霓虹与穿越镜是氛围工具，光只在光源附近着色、招牌运镜点到为止。

## 核心美学

- **未来科技 × 都市衰败**的高对比：巨型摩天楼、飞车、霓虹街道叠在"永夜下雨的城市"noir 底子上；新旧脏乱与未来辉光的对撞。来源：Color Culture《Blade Runner (1982)》；Atmosfera Mag。
- **用雨 / 烟 / 雾雕刻光**：持续的大气介质让光成为"可见的光束 / 体积光"，也把镜头之间连缀起来。来源：ASC《Cronenweth's Photography》；CinemaTyler。
- **霓虹实用光**：招牌 / 显示器 / 街灯把饱和色（蓝红绿）打在湿反光的地面与人脸上——"neon noir"。来源：Color Culture。
- **前景柔光 + 硬逆光 + 烟**：常从下方打脸、用水面 / 反光提供 uplight；"暖色柔前光 + 硬逆光 + 烟"是最典型特征。来源：ASC。
- **纵深分层**：雨窗 / 蒸汽 / 人群做前景，把视线引向深处，很少给平面画框。来源：Color Culture。

## 情境化提醒

- **光只在光源附近**：霓虹是底色但阴影要保持中性、深黑，不是全画面泛光。
- **FPV 穿越长镜 / 手持震动是点睛**：用于转场与失序时刻，别让每个镜头都在穿越、都在抖。
- 东方谱系（《攻壳机动队》）以多层城市空间、高低科技并置强化孤独与人机关系。来源：HSSR《Spatial Narratives in Cyberpunk Films》。

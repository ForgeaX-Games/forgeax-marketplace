# 调研 · 莫兰迪灰调（低饱和中性灰色系）

> 得名自画家色彩体系(公共美学概念)，非某部影片。成品只用原创描述。

## 核心

- 每种颜色按比例掺灰 → 整体光泽压暗、对比弱，安静和谐。来源：clausiuspress 论文《Morandi color system》、tourboxtech。
- 灰白/灰蓝/灰赭等窄灰谱内的微妙明度色相变化；**不用纯灰、不用纯黑白**。来源：JSSH 论文《Grey Tones》、tourboxtech。
- 低饱和缺"侵略性"，情绪平静舒缓；影视里用于服化道/场景/布光/后期统一。来源：globethesis 论文《Morandi color in film》。
- 布光柔而均匀、约 4000K 中性白防偏色。

## 落地到调色

全色掺灰的低饱和 + 低对比 + 无纯黑白 + 柔光。整片恒定，昼夜/情绪靠灰调内冷暖与明度微移。

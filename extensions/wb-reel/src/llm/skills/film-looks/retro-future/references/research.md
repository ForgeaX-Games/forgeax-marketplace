# 调研 · 复古未来主义（合成器波 / Outrun 美学）

> 类型美学，非某部影片。成品只用原创描述，不写片名。

## 核心

- 1980s 怀旧的"过去想象的未来"：霓虹网格、条纹落日(Retrosun)、铬金字、棕榈剪影。来源：Aesthetics Wiki《Synthwave》、visualnomic。
- 色板：hot pink #FF007F / electric blue / purple #8000FF / cyan，超饱和合成色，深黑打底。来源：synpop《What Is Synthwave Art Style》。
- 手法：高对比渐变、bloom 辉光、VHS/CRT 失真、色差(chromatic aberration)。来源：retrowave.com、gifPaper。

## 落地到调色

品红↔青互补高对比 + 深紫/深靛暗部 + 铬金高光 + 轻 VHS 辉光/扫描线。整片恒定，昼夜只调亮度与霓虹密度。

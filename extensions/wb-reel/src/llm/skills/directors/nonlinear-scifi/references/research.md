# 调研 · 非线性科幻 · 结构叙事（nonlinear-scifi）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名 / 真实品牌名。真名真作品 / 品牌（含 IMAX、70mm）仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 克里斯托弗·诺兰（Christopher Nolan）的非线性 / 交叉剪辑结构与实拍大画幅美学。代表作：《记忆碎片》《致命魔术》《盗梦空间》《星际穿越》《敦刻尔克》《信条》《奥本海默》。
- 品牌术语溯源：诺兰推广 70mm / IMAX 大画幅放映——成品统一改称"大画幅（large-format）"以去品牌名。

## 招牌手法（要点）

- **交叉剪辑（crosscutting）是核心结构手段**：Bordwell 指出诺兰把交叉剪辑当成塑造整片的初始承诺——把可顺叙的故事拆成 2–3 段并行相位交替。
- **非线性 / 嵌套叙事**：逆序、多视角、相对论式的时间层。
- **省略式 / 直觉式剪辑**：制造强度与主观性，观众靠推理补规则；不写详细分镜表，只对大动作打分镜。
- **实拍优先**：极少 CGI，尽量 in-camera；VFX 镜头数远少于同体量大片。
- **大画幅**：70mm / IMAX，宽镜奇观（成品去品牌，写"大画幅"）。
- **摄影**：自然光/纪录片式布光、实景/大型实体布景；手持长镜被锁定单人镜与过肩镜打断；动作多机位、文戏单机。
- **音景**：实验性声场、低频、滴答/倒计时式推进。

## 落地到本 skill 的手法

- 大画幅壮阔 wide ↔ 贴脸 close 两极；"手持 + 锁定 + OTS"三件套。
- 交叉剪辑汇合 / 大画幅奇观 / 实拍实体效果列为稀缺点睛（交叉剪辑是跨场结构，单片段用镜位交替暗示）。
- 自然光写实 + 居中几何 + 蓝钢大地冷静调 + 滴答音景为底色。

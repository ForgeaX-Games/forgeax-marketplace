# 调研 · 断章对话 · 停顿张力（pulp-dialogue）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 昆汀·塔伦蒂诺（Quentin Tarantino）的章节化非线性叙事、长局对话与暴力速决。代表作：《落水狗》《低俗小说》《危险关系(Jackie Brown)》《杀死比尔》《无耻混蛋》《好莱坞往事》。
- 手法溯源：章节标题的用法可上溯至戈达尔《随心所欲》(Vivre Sa Vie)；"长局对话/十分钟对峙"的节奏感师法赛尔乔·莱昂内的西部片——成品去真名，写成"经典西部片的十分钟对峙感"。

## 招牌手法（要点）

- **章节化非线性**：章节标题把故事切成自成一体段落，靠复现人物/地点缝合，时间线错置。
- **长局对话（"long game"）**：从平庸话题（汉堡、电视）起手建立虚假正常，越拖张力越大，暴力一瞬爆发；"张力在停顿不在拳头"。
- **对话即角色/互文**：oblique exposition，靠"怎么说"而非"说什么"塑造人物。
- **招牌镜头**：后备箱镜头（trunk shot，低角 POV，几乎每片都有）；墨西哥对峙（Mexican standoff，多人互相举枪，映射不确定的忠诚/权力）；脚/物件的极端特写；急推变焦（crash zoom）。
- **剪辑**：推轨长镜/流畅跟拍 与 暴力段的凌厉肌肉感快剪对比；对话戏用常规覆盖（正反打），把重心给表演与台词节奏而非炫技。
- **暴力**：长铺垫后 quick, shocking, efficient；常接反差流行金曲。
- **质感**：饱和复古、类型片致敬（剥削片/西部片/功夫片）、胶片颗粒。

## 落地到本 skill 的手法

- 对话以 medium/two-shot 稳看表演，重点切 extreme close-up；推轨长镜 baseline + 偶尔急推变焦。
- 后备箱镜头 / 多人对峙 / 急推变焦 / 暴力速决快剪列为稀缺招牌点睛；对话段反招牌别用快切。
- 饱和复古类型片质感 + 胶片颗粒 + 台词优先为底色。

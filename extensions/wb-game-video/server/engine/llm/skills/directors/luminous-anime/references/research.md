# 调研 · 高光日漫 · 光之抒情（luminous-anime）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 新海诚（Makoto Shinkai）的高光 / 高细节抒情日漫美学。代表作：《你的名字。》《天气之子》《秒速五厘米》《言叶之庭》《铃芽之旅》。
- 反招牌参照：《你的名字。》黄昏（"逢魔时刻"）关键戏反而把画面调成中性、克制光晕——成品写成"黄昏关键戏反而调成中性"的通用陈述。

## 核心美学要点

- "世界本身已足够美"：让观众相信"此刻的天空只属于这个角色"；细节密度是签名。
- 快而不急（约 3s 一切）+ 大量空镜插入（天空/电线/水面反光/光斑）作和弦过门；匹配切多（天空接天花板）。
- 上升 crane 让"天空在转" + 节制的 lens flare 作情绪锚点（每次出现要有理由）。
- 必有强逆光、锐利边缘高光；高饱和蓝天 + 橙金暖光互补；多层次云不平涂。
- 节奏似流行歌 B 段，情绪点约在 2/3 处爆发，配乐贴拍。

## 落地到本 skill 的手法

- wide↔close 两极切 + 空镜过门（约三秒一景）；35mm 广角为主。
- 上升 crane / lens flare / 匹配切列为稀缺点睛；紧张段反招牌收紧 close、去唯美空镜。
- 强逆光边缘高光 + 高饱和互补 + 多层次云 + 高细节为底色。

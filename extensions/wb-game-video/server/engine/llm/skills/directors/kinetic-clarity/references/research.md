# 调研 · 清晰动能 · 快而不糊（kinetic-clarity）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 乔治·米勒（George Miller）的动能派动作调度与"中心构图法则"。代表作：《疯狂麦克斯：狂暴之路》系列。
- 反招牌参照：米勒本人受访明说中心构图 / 极快切只用在最快的动作段，不需要快切的段落随意构图——成品写成通用陈述。

## 核心美学要点

- "看不清即失败"：快而不糊，每一帧都能被看懂；清晰度优先。
- 中心构图法则（eye-trace / centered framing）：无论怎么甩，主体永远回到画面正中，眼睛不用追。
- 切点 1-2s 但每切有动作意图；能量跨镜延续（上一镜飞出=下一镜飞入）。
- 子弹时间 / 升格只压关键撞击拍，慢镜后必接正常速回归。
- 短焦广角（24-35mm）临场与畸变；高对比硬光 + 烟尘；高饱和橙青互补。
- 节奏如过山车：加速—持续—短暂失重—再加速，静止不超过 1s。

## 落地到本 skill 的手法

- medium+close 把动作拍清楚，间歇切 wide 喘息；低角跟拍 + 甩镜 baseline。
- 子弹时间 / 升格慢镜 / 碎片击屏列为稀缺点睛；铺陈段反招牌真正稳下来。
- 橙青互补 + 硬光烟尘 + 中心构图为底色。

# 调研 · 冷峻精算 · 克制黑色（precision-noir）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 大卫·芬奇（David Fincher）的极致精确 / 冷峻控制美学。代表作：《七宗罪》《社交网络》《消失的爱人》《十二宫》《龙纹身的女孩》。

## 核心美学要点

- "精确即风格"：色温、剪辑帧数、演员表演时机都被严格控制；反抒情、冷静到近乎冷漠的注视。
- 不对称剪辑：长镜（15s+）与极短切（2-3 帧）交错，永不回到"正常节奏"；硬切 / 匹配切、少叠化。
- 不对称 A/B 反打：一方 OTS 半脸阴影、另一方平光全脸，暗示"谁在说谎"。
- 锁定机位为主，不可见的极缓 track-in 只压在张力累积那一拍；手持只给失控瞬间。
- 长焦（85/100mm）压缩背景；单光源、阴影占 60%+；冷绿冷青灰褐去饱和。
- "不加快"制造焦虑；台词间留 0.3-0.5s 呼吸。

## 落地到本 skill 的手法

- close/medium 为主 + 不对称反打；锁定机位 baseline。
- 极缓 track-in / 2-3 帧极短切 / 精确匹配切列为稀缺点睛。
- 冷绿冷青灰褐去饱和 + 长焦压缩 + 单光源大阴影为底色。
- 时长窗口：凝视 8-15s，失控/暴力约 4s。

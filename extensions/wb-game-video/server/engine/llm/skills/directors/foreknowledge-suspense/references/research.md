# 调研 · 先知悬疑 · 信息差惊悚（foreknowledge-suspense）

> 此为内部调研，仅供人读 / 审计。成品（SKILL.md / prompt）只用原创的风格描述，不写真实导演名 / 真实片名。真名真作品仅在本文件出现，不会进入模型提示词。

## 真实灵感来源（不进模型）

- 阿尔弗雷德·希区柯克（Alfred Hitchcock）的悬念理论与技法。代表作：《精神病患者》《后窗》《眩晕》《西北偏北》《群鸟》。
- 术语溯源：Dolly Zoom（推轨变焦）因《眩晕》而广为人知，业界俗称亦含其名——成品统一改称"移焦变焦 / 推拉反向变焦的眩晕变形"以去真名。

## 核心美学要点

- "悬念≠惊吓"：让观众比角色先知危险（"桌下有炸弹而角色不知"的信息差），悬念来自等待而非 jump-scare。
- 延迟揭示：先切反应镜（听到未看到），再切源头；POV 主观 ↔ 反应镜交替。
- Dolly Zoom：推轨与变焦反向运动造成空间眩晕变形，留给认知崩塌那一拍。
- 声音先行：脚步/呼吸/滴答比主体出画早半秒。
- 顶光半脸阴影、影子比实体更有信息量；偏冷高反差，唯一暖色锁"危险物"。
- 节奏如心电图：长静（10-15s）→ 极短动作（0.5s）→ 回到静。

## 落地到本 skill 的手法

- OTS/medium 建立"偷看"视角，关键信息切 extreme close-up；全知 high-angle wide 揭示信息差。
- 签名 Dolly Zoom（改称"移焦变焦"）、唯一暖色锁危险物列为稀缺点睛。
- 时长窗口：凝视/等待 10-15s，切入约 4s。

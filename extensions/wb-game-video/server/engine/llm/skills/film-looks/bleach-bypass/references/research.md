# 调研 · 漂白旁路（bleach bypass / 银盐保留 / skip bleach）

> 公共冲印/调色技法，非某部影片。成品只用原创描述。

## 核心

- 冲印时弱化/跳过漂白步骤，金属银与彩色染料一起保留 → 相当于黑白图叠在彩色上。来源：Wikipedia《Bleach bypass》、Kodak 处理技法页。
- 效果：低饱和、深黑、爆高光、高对比、宽容度下降、颗粒更明显；常配欠曝一档。来源：Kodak、Grokipedia。
- 数字复刻：叠一层黑白版 + Overlay/Hardlight 合成，末端加颗粒。来源：Boris FX《Bleach Bypass in DaVinci Resolve》。
- 气质：脏、冷、凝重，多用于战争/惊悚/历史/独立片。来源：Boris FX。

## 落地到调色

低饱和 + 高对比 + 深黑 + 硬高光 + 粗颗粒 + 冷金属灰。整片恒定，昼夜靠明暗，不回饱和。

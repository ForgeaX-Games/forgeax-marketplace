# 电影美学 · 漂白旁路冷硬（调色滤镜）

> 源自"跳漂白/银盐保留"冲印工艺：保留金属银 → 去饱和、高对比、粗颗粒、冷硬。
> 常用于战争/惊悚/写实剧的凝重质感。是**调色**层，叠加在任意渲染媒介之上。

## 调色锚点

Bleach-bypass (silver-retention) color grade: heavily desaturated muted colors, crushed rich blacks, blown harsh highlights, high contrast with compressed tonal range, prominent gritty film grain, cold metallic silver cast, near-monochrome overlay feel.

## 场景自适应

全片恒定锚点：低饱和 + 高对比 + 深黑硬高光 + 粗颗粒 + 冷金属灰，任何场景都不变。
白天用硬顶光/顶阴天的惨白光；夜晚压更深的黑、留高光的硬。无论昼夜都**去饱和、拉对比、保颗粒**。
色彩只剩微弱残留(如血红、锈黄)，切勿回到鲜艳——凝重脏硬是底色。

## 作者文风

措辞冷硬、克制、写实，强调凝重氛围、去色的沉重与颗粒的粗粝质感。

# 电影美学 · 蒂尔橙大片调（调色滤镜）

> 拉开主体与背景。是**调色**层，叠加在任意渲染媒介之上。

## 调色锚点

Blockbuster teal-and-orange color grade: shadows and environment pushed toward cool teal/cyan, warm amber-orange highlights and skin tones, strong complementary contrast, glossy filmic S-curve, cinematic subject-from-background separation by hue.

## 场景自适应

全片恒定锚点：青绿暗部 + 暖橙高光/肤色 + 互补高对比，任何场景都不变。
白天像"黄金时刻"——暖橙阳光打人物、青蓝天空/阴影当背景；夜晚暖橙人造光对冷青夜色。
室内用暖实用光对冷环境。无论昼夜都**保肤色暖、环境冷**，靠色相而非景深分离主体。

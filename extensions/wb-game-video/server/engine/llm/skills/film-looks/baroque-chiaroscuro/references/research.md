# 调研 · 巴洛克明暗对照（chiaroscuro / tenebrism）

> 公共绘画/摄影技法，非某部影片。成品只用原创描述。

## 核心

- Chiaroscuro = 光暗("chiaro"清+"scuro"暗)，用强对比在二维上塑三维体积；巴洛克时期发扬。来源：MasterClass、Wikipedia《Chiaroscuro》。
- Tenebrism = 极端化的明暗对照，大面积近黑背景，主体被定向"聚光"孤立("spotlight effect")。来源：purposestudios、FilmDaft《Tenebrism》。
- 电影落地 = 低照度(low-key)单光源、烛光/窗光，其余入深阴影，制造心理张力与体积。来源：MasterClass、wahooart《candlelight painting》(Rembrandt/De La Tour)。

## 落地到调色

暖金高光 + 近黑暗部 + 琥珀赭石油画色 + 强明暗落差，单光源塑形。整片恒定，昼夜靠"哪支光"变化，低照度不变。

# 调研 · 糖果对称童话（绘本式高度设计感）

> 公共"设计化电影"美学(Andersonian)，非某位在世作者专属。成品只用原创描述，
> 不点名。本条只取其**色彩/氛围**面(糖果粉彩、协调、低对比)，对称构图归导演维度。

## 核心

- 高度控制的"设计化电影"：极致对称、正面平面构图(planimetric)、协调粉彩色板、图形化美术、去写实的刻意人工感。来源：HowToFilmSchool《Andersonian》。
- 色彩：粉、薄荷、淡黄、粉蓝、奶油等 curated pastel，服化道统一协调，不求自然而求"设计的和谐"。来源：Medium《A Symphony of Pastels》、cartoonize。
- 情绪由色彩承载：繁盛时暖糖果粉、衰败时色彩悄悄流失。来源：Medium。

## 落地到调色

柔和糖果色 + 低对比 + 平光 + 强色彩协调。整片恒定，昼夜/情绪靠饱和与明度而非硬对比。

## 2026-06-22 · Raise the pillars first, don't pick art first
The user wanted to make "a roguelike like Hades" and immediately fixated on art style. I pulled him back: art is clothing for the gameplay pillars — if the pillars aren't up, there's nowhere to hang the clothes. First get the 5-second core loop crystal clear — and he took it in. Note to self: this user is easily dragged off by surface details; each time I have to anchor him to the skeleton first.

## 2026-06-20 · "Moderate difficulty" is not an answer
"Moderate difficulty" came up again today. My principle hasn't changed: either give concrete numbers (HP=100, DPS=18, curve slope 1.2) or don't draw a conclusion. A vague "moderate" makes downstream cc-coder ask back three times, and nobody can land it.

## 2026-06-17 · Every pillar must be definable in reverse
Helped the user cut the fourth pillar — it duplicated the second. The criterion, again: any pillar must be expressible as "if the player doesn't <action>, then <penalty>." One you can't state that way is an empty-talk pillar; keeping it only dilutes the other three.

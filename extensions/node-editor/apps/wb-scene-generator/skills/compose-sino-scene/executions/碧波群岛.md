## 场景效果描述

整张场景在 80×80 格的地图上实现了「碧波群岛」的完整游戏地形：
1. **地形层**：三座热带岛屿（一大两小）浮于水域上，主岛覆盖地图大部分区域，体现群岛氛围
2. **港湾区（东侧）**：港口码头 + 海鲜集市 + 珍珠坊 + 水手公会四栋建筑密集布置；港口码头带内部结构（对应海鸥酒馆）
3. **雨林区（西侧）**：潮汐神庙深藏西侧，带内部结构（对应神庙内殿）；大量热带巨叶植被覆盖
4. **道路网**：石板路连通所有六个关键节点（含出生点），MST 路径确保全局连通
5. **地标**：灯塔立于港口东端、休眠火山岩锥耸立中央、椰林树丛点缀雨林
6. **水景**：火山口湖为自然湖泊（LakeRegions 生成）

# 内部边界距离场 / FieldInnerDistance（`alg_field_inner_distance`）

计算输入区域内每个有效格到「**内部 0 区域边界**」的多源 BFS 距离场。与通用的 `alg_field_distance` 最大的不同是：它会先区分网格里的 **0 格** 是「外部背景」还是「内部洞」，从而只把**内部边界**当作距离源（可选并入外缘）。

## 它解决什么问题

一张区域网格里，值为 `0` 的格子其实有两类：

- **外部背景**：与网格四边连通的 `0`（区域外面的空白）。
- **内部洞**：被有效区域完全包围的 `0`（例如海洋里的岛屿、地块里的天井）。

通用距离场无法区分这两者。本电池用一次 border flood-fill 把所有从网格边缘可达的 `0` 标记为外部背景，剩下的 `0` 即内部洞。

## 距离源的选取

- **默认（`includeOuterBoundary=false`）**：源 = 有效格中 4-邻接到**内部洞**的格 → 内部 0 边界。
- **`includeOuterBoundary=true`**：在上面的基础上，再并入**外缘格**（位于网格边缘、或 4-邻接到外部背景 `0` 格的有效格）作为源。

源格距离为 `0`，向区域内部逐层 `+1`，BFS 只在有效格内传播。

## 两种典型用例（对称）

| 输入区域 | 有效格 | `includeOuterBoundary` | 距离含义 | 近处 / 远处 |
| --- | --- | --- | --- | --- |
| 海洋（内含岛屿） | 水 | `false` | 到最近岛岸的距离 | 浅海 / 深海 |
| 岛屿 · 实心陆地 | 陆地 | `true` | 到外缘海岸线的距离 | 海岸线 / 内陆 |

> 岛屿/实心陆地通常**没有内部洞**，若用默认 `false` 将没有任何源、整片输出 `-1`。这类区域必须开 `includeOuterBoundary=true`。

## 输入

| 端口 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `region` | `grid` | （必填） | 0/1 或多值区网格，非零格为有效格 |
| `includeOuterBoundary` | `bool` | `false` | 是否把区域外缘也作为距离源 |
| `connectivity` | `number` | `4` | BFS 邻接：`4` 正交，`8` 含对角 |
| `normalize` | `bool` | `false` | 是否把可达距离线性归一化到 `[0,1]` |

## 输出

| 端口 | 类型 | 说明 |
| --- | --- | --- |
| `field` | `grid` | 距离场 `number[][]`：源格 `0`，逐层 `+1`；region 外无效格 `0`；region 内不可达的有效格 `-1`。`normalize=true` 时可达距离归一化到 `[0,1]`。 |

## 备注

- 输出是**连续标量场**而非 0/1 掩码。要据此切出子区域，请接 `alg_field_threshold`。
- `-1` 用于区分「区域外无效格（0）」与「区域内但 BFS 不可达的有效格（-1）」；阈值切分时应注意这一点。

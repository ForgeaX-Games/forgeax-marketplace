# 坡道掩码生成 (ramp_mask_gen)

读取单张网格中每个区域，在其底边生成一个 2×2 坡道掩码块：上两格在区域内部，下两格在区域外部。支持指定坡道横向位置（0~1）。

## 数据格式（DataTree）

输入 `inputGrid` 与输出 `outputGrid` 均为 `grid` / `access:item`：每次只处理单张网格，网格列表由引擎自动逐张 fanout / 重组，无需算子内部维护列表或合并逻辑。

## 功能特点

1. **单网格处理**：每次处理一张网格，对其中每个非零区域生成坡道；列表由 DataTree 引擎负责
2. **指定或随机坡道位置**：通过 `rampPosition` 端口（0~1）控制坡道在底边的横向位置；不填（-1）则随机
3. **保留原值**：坡道格子值等于所属区域值，便于下游识别归属

## 坡道示意

```
...  区域内容  ...
[ v ][ v ]         ← 上两格（区域内，底边格子）
[ v ][ v ]         ← 下两格（区域外，底行下一行）
```

## 输入参数

| 参数名 | 类型 | access | 默认值 | 说明 |
|--------|------|--------|--------|------|
| inputGrid | grid | item | — | 输入网格（单张），每个非零值视为独立区域 |
| rampPosition | number | item | -1 | 坡道横向位置 0~1（0=最左，1=最右）；-1 表示随机 |
| seed | number | item | 0 | 随机种子（仅随机模式生效），0 使用当前时间 |

## 输出参数

| 参数名 | 类型 | access | 说明 |
|--------|------|--------|------|
| outputGrid | grid | item | 坡道掩码网格，坡道格子为原区域值，其余为 0 |

## rampPosition 说明

- 取值范围 `0~1`，线性映射到区域底边所有合法候选位置（按列从左到右排序）
- `0` = 最左侧合法坡道位置，`1` = 最右侧合法坡道位置，`0.5` ≈ 居中
- `-1`（默认）或超出 `[0, 1]` 范围时退回随机模式，使用 `seed` 控制

## 注意事项

1. 区域底行已在网格最后一行时，下方两格超出边界，该区域坡道跳过
2. 区域底边宽度为 1（单列）时，无法构成 2 格宽坡道，该区域跳过
3. 同一格被多个区域坡道覆盖时，后处理的区域值会覆盖前一个
4. `rampPosition` 指定的是候选位置索引比例，而非绝对列坐标

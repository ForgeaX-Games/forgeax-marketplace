# 随机矩形区域生成 (random_rect_zone_gen)

在单张输入网格的指定区域内随机散布指定数量、指定大小范围的轴对齐**不重叠**矩形，全部写入一张多值网格（每个矩形一个递增 id），支持不规则区域和多值掩码中的异形区域。

> **DataTree 数据格式**：`inputGrid` / `outputGrid` 均为 `grid`（`access: item`）。本电池每次只处理单张网格，网格列表由引擎按 DataTree 自动逐张 fanout / 重组。

## 功能特点

1. **兼容二值与多值网格**：`targetValue=0` 时以 `0` 为禁区，所有非零格均可放矩形；填非零值时精确匹配该掩码ID，支持不规则区域和异形区域（如仅在区域3内生成矩形）
2. **不重叠 + 间距约束**：矩形互不重叠，并可用 `minDistance` 控制相邻矩形最近边的最小间距
3. **离散程度控制**：`dispersion` 越大，新矩形越倾向放置在远离已有矩形的位置
4. **多值网格输出**：每个矩形一个从 `max+1` 起递增的 id，配合 `outputNameList`，下游可接 `grid_split_by_value` 拆分
5. **输出实际数量**：`placedCount` 端口告知最终成功放置了多少个矩形

## 适用情况

- 在地形/地块掩码内快速散布建筑底座、农田、广场等矩形功能区
- 在房间网格中填充桌子、床铺、柜子等矩形家具轮廓
- 任何需要在有界非零区域内随机摆放矩形的 PCG 场景
- 不适用于需要矩形可互相重叠的情况（本电池保证矩形不重叠）

## 基本使用方法

1. 将上游网格连接到 `inputGrid` 输入端口
2. 调整 `count`、`minSize`/`maxSize` 控制数量和大小
3. 用 `minDistance`、`dispersion` 控制间距与离散程度
4. 执行后从 `outputGrid` 获取多值结果，`placedCount` 查看实际放置数

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| inputGrid | grid | — | 单张输入网格，支持二值或多值掩码（DataTree 逐张处理） |
| targetValue | number | 0 | 目标区域掩码值，0=任意非零，非零=精确匹配该ID |
| count | number | 5 | 目标矩形数量 |
| minSize | number | 13 | 矩形最小宽高（格数），宽高各自独立随机 |
| maxSize | number | 19 | 矩形最大宽高（格数） |
| minDistance | number | 2 | 相邻矩形最近边之间的最小格数间距，0=允许紧靠 |
| dispersion | number | 0.6 | 离散程度：0=随机集中，1=尽量分散 |
| seed | number | 0 | 随机种子，0 = 自动随机 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| outputGrid | grid | 单张多值网格：每个矩形地块一个递增 id，0=空白 |
| outputNameList | array | 地块名称清单 `[{id, name:'地块 N', type:'tile'}]`，与网格中的 id 一一对应 |
| placedCount | number | 实际成功放置的矩形数量 |

## 注意事项

1. **targetValue 用法**：默认 `0` 表示"任意非零"模式；需要只在某个特定区域（如掩码值3的区域）放矩形时，将 `targetValue` 设为 `3` 即可
2. **矩形不重叠**：本电池保证矩形互不重叠，并按 `minDistance` 维持最小间距
3. **id 从 max+1 起递增**：填充值自动取本网格最大值 + 1，避免与已有掩码冲突
4. **实际放置数可能少于 count**：当区域狭窄或矩形较大时，多次尝试仍找不到合法位置，该矩形会被跳过；可缩小矩形尺寸或减小 `minDistance`
5. **seed=0 每次随机**：如需可复现结果，请填写非零种子

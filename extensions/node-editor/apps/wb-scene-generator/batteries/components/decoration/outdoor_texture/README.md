# 室外纹理 (outdoor_texture)

根据单张掩码网格和温度/湿度参数，用 Whittaker 生物群系模型（温度+湿度双轴）与多层分形噪声生成室外地面纹理（草地/泥土/碎石/沙地/湿草/落叶/苔藓/雪地），输出单张多值网格与名称清单。

## 数据格式（DataTree）

输入 `inputGrid` 与输出 `outputGrid` 均为 `grid` / `access:item`：每次只处理单张网格，网格列表由引擎自动逐张 fanout / 重组。多种纹理合并在同一张多值网格中输出，下游可 `grid_split_by_value` 按值拆分后分别命名。

## 原理

1. 多层 FBM 噪声 + 域扭曲生成温度/湿度/伪海拔场
2. 每个生物群系按高斯距离核（到群系温湿中心）+ 边缘/海拔偏好打分，加权随机选取
3. 两轮邻域一致性平滑 + 生态过渡修正（不合理邻接插入中间类型）
4. 名称：用 seed 随机选定一整套「同材质 tile 变体」8 连名，同次运行风格一致

## 输入参数

| 参数名 | 类型 | access | 默认值 | 说明 |
|--------|------|--------|--------|------|
| inputGrid | grid | item | — | 单张掩码网格，非零为有效地面 |
| temperature | number | item | 0.5 | 全局温度偏置 0~1 |
| moisture | number | item | 0.5 | 全局湿度偏置 0~1 |
| seed | number | item | 0 | 随机种子，0 使用当前时间戳 |

## 输出参数

| 参数名 | 类型 | access | 说明 |
|--------|------|--------|------|
| outputGrid | grid | item | 多值生物群系网格，每格为纹理 id（1=草地…8=雪地）或 0 |
| nameList | array | item | 实际出现的纹理条目 `[{id, name, type:'tile'}]`，按 id 1→8 有序 |

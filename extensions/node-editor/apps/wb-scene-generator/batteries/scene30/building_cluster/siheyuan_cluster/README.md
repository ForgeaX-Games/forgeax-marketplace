# 四合院组群 (siheyuan_cluster)

生成传统四合院院落布局：一圈贴齐外边界的围墙，把若干横向/纵向矩形房屋用围墙、围廊连接成院落组群。可控制房屋数量（进数）。

## 结构（参考标准三进院落）

- **围墙**：外围一圈，贴齐 region 非零包围盒的外边界；可在底墙开院门。
- **横向房屋带**：`进数+1` 条，贯穿院落宽度——顶为正房、底为倒座房、中间为厅堂。
- **纵向厢房**：每个院落左右各一座（西厢房 / 东厢房）。
- **围廊**：每个院落中庭四周一圈，把四面房屋串起来。

**房屋数量 = 3 × 进数 + 1**（进数=1 即标准四合院，4 座房屋）。

## 基本使用方法

1. 把区域网格接入 `输入区域`（围墙贴齐其外边界）。
2. 用 `进数(院落数)` 控制规模与房屋数量。
3. 按需调 `房屋进深` / `厢房宽度` / `围墙厚度` / `围廊宽度` / `院门宽度`。
4. 输出 `合并网格`（多值，可接 grid_split_by_value→grid2node）或 `房屋列表` / `围墙` / `围廊` 分层使用。

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| region | grid | — | 区域网格，围墙贴齐其外边界 |
| courtyards | number | 1 | 进数（院落数），房屋数=3N+1 |
| wallThk | number | 1 | 围墙厚度 |
| hallDepth | number | 4 | 横向房屋进深（行） |
| wingWidth | number | 4 | 纵向厢房宽度（列） |
| corridorThk | number | 1 | 围廊宽度，0=无围廊 |
| gateWidth | number | 2 | 底墙院门宽度，0=封闭 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| outputGrid | grid | 合并多值网格（房屋各 id + 围廊 + 围墙各一值） |
| houses | grid (list) | 每座房屋一张 0/1 网格 |
| wall | grid | 围墙 0/1 网格 |
| corridor | grid | 围廊 0/1 网格 |
| outputNameList | array | 名称清单 [{id,name,type}] |

## 注意事项

1. **坐标约定**：x→列、y→行。
2. **自适应**：`房屋进深`/`厢房宽度` 放不下时自动缩小以容纳指定进数与中庭。
3. **房屋顺序**：正房→厅堂…→倒座房→各院落西厢房/东厢房。

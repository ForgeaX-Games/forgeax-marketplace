# 四合院围墙 (siheyuan_wall_frame)

输入多个矩形，取每个矩形长边方向的中心线，按环形顺序把它们用连接段首尾串成一个闭合的「框」，输出围墙网格。

## 功能特点

1. **长边中心线**：每个矩形取最小包围盒，沿其较长边方向画一条中心线（脊线）。
2. **闭合成框**：所有矩形按围绕整体质心的极角排成环形，贪心首尾相接，串成一条闭合折线（围墙）。
3. **两种输入兼容**：既接 0/1 网格列表（每张一个矩形），也接单张多值网格（每个不同非零 id 视为一个矩形，自动拆分）。
4. **可调线宽**：`thickness` 控制围墙粗细。

## 基本使用方法

1. 把矩形接入 `矩形列表`：
   - 上游为 `区域点集生矩形`（points2rects）等输出的矩形网格列表，直接连入；
   - 或上游为 `BSP矩形生成`（bsp_rect_gen）的单张多值网格，也可直接连入（自动按 id 拆分）。
2. 按需设置 `围墙厚度`。
3. 输出 `围墙网格` 可接 mask/scene 可视化或下游道路/墙体电池。

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| rects | grid (list) | — | 矩形列表：0/1 网格列表，或单张多值网格 |
| thickness | number | 1 | 围墙线宽（格数） |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| wall | grid | 围墙网格，闭合框线段处为 1，其余为 0 |

## 注意事项

1. **坐标约定**：x→列、y→行。
2. **输出尺寸**：取所有输入网格的最大行列，避免越界。
3. **单个矩形**：闭合折线退化为该矩形的中心线本身。

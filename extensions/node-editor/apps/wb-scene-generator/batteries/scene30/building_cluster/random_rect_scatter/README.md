# 随机生成矩形 (random_rect_scatter)

根据输入点位，在每个点周围随机生成若干矩形，可控制矩形与点之间的大致距离。

## 功能特点

1. **点周围散布**：每个输入点周围生成 `countPerPoint` 个矩形，方向随机。
2. **可控距离**：`distance` 指定矩形与点之间的大致距离（点到矩形中心），`distanceJitter` 控制随机波动范围 ±。
3. **随机尺寸**：矩形宽高在 `minSize..maxSize` 内随机。
4. **可复现**：支持随机种子，相同种子产生相同结果。
5. **双输出**：多值网格（每矩形一个递增 id，便于预览/拆分）+ 0/1 矩形网格列表。

## 基本使用方法

1. 把区域/画布网格接入 `输入区域`（仅定义输出尺寸）。
2. 把点集接入 `中心点集`（如采样点、POI 点位）。
3. 调 `与点距离` / `距离波动` 控制矩形离点远近，`每点矩形数`、`最小/最大边长` 控制数量与大小。
4. 输出 `矩形网格`（多值）或 `矩形列表`（0/1 列表）→ 可直接接入 `四合院围墙`（siheyuan_wall_frame）串成围墙。

## 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| region | grid | — | 区域/画布网格，仅定义输出尺寸 |
| points | point2d (list) | — | 中心点集，x→列、y→行 |
| countPerPoint | number | 3 | 每个点生成的矩形数量 |
| distance | number | 6 | 矩形与点的大致中心距 |
| distanceJitter | number | 2 | 距离随机波动 ± |
| minSize | number | 2 | 矩形最小边长 |
| maxSize | number | 5 | 矩形最大边长 |
| seed | number | 0 | 随机种子，0 使用当前时间 |

## 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| outputGrid | grid | 多值网格，每个矩形一个递增 id |
| rects | grid (list) | 每个矩形一张 0/1 网格 |

## 注意事项

1. **坐标约定**：x→列、y→行。
2. **边界裁剪**：矩形按 region 边界裁剪；完全越界的矩形在列表中对应全 0 网格、在多值网格中无痕。
3. **距离含义**：`distance` 是点到矩形中心的距离，非边缘间隙。
